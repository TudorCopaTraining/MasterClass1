How To Run This Activity

The Wildcard Filmmaking Challenge forces students to think outside cliché narratives, practice inventive problem-solving, and adapt on their feet.

Challenge Ground Rules:
  1. Every group or student must feature their assigned element visibly in their story.
  2. The element cannot simply be mentioned in passing—it must influence a character's decision or action.
  3. Filmmakers have 3 minutes to plan their initial concept pitch.

Classroom Hosting Tips:

  • GitHub Pages Ready: Host this single file directly in a GitHub repository as index.html with Pages enabled.
  • Projector Mode: Project the Solo Draw tab onto your classroom whiteboard for dramatic individual student rolls.
  • Quick Export: Use the Roster tab to instantly output a CSV or printable checklist for grading and crew check-ins.
